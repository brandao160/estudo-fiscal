IA para Gerar Questões

Escolha Gemini (grátis, precisa de uma chave de API do Google AI Studio) ou Claude (pago, precisa de uma chave de API da Anthropic). A chave fica salva só neste navegador e a chamada vai direto daqui pra IA — este site não vê nem guarda sua chave. Se você já configurou uma chave ao importar o edital em PDF no Menu Inicial, ela já aparece preenchida abaixo.

Crie sua própria chave de API no Google AI Studio (não pede cartão de crédito, tem cota diária gratuita generosa). A IA primeiro pesquisa na web tentando achar questões reais já aplicadas em provas antes de criar uma inédita (buscas incluídas na cota grátis — 5.000/mês). Criar chave grátis →
Precisa da sua própria chave de API da Anthropic (Claude), que é paga. A IA pesquisa na web tentando achar questões reais antes de criar uma inédita — cada busca consome créditos à parte dos tokens, além do custo normal do lote. Criar/gerenciar chave →
Modo automático: usa uma cota compartilhada da OpenRouter (configurada por quem administra este site), sem precisar colar chave nenhuma — mas tem limite diário por pessoa. Se esgotar, use Gemini, Claude ou sua própria chave OpenRouter. Não pesquisa questões reais (só gera inéditas).

Só precisa preencher uma vez (fica salvo neste navegador). Veja functions/questoes-proxy.js no repositório do projeto pra saber como implantar esse proxy (Cloudflare Pages Functions).
